03 / UNDER THE SURFACE

The animation explains it.
The transactions prove it.

01

Write together.

An order change and its outbox event share a source transaction. A crash cannot commit one without the other.

02

Commit together.

The projection, receipt, quarantine result and checkpoint share one sink transaction. An injected crash rolls them back.

03

Replay safely.

Envelope identity detects exact replays. Entity versions and delete tombstones prevent stale updates from changing current state.

Order command → Source SQLite: order + outbox
Ordered poll → Sink SQLite: state + receipt + checkpoint
SQL snapshots → Recorded JSON → This interactive replay

Single-host SQLite demonstration, built on LedgerStream. No Kafka or cloud deployment; no exactly-once claim across external services. Invalid payload and stale-version scenarios use explicitly labeled transport fixtures.
